# Internal packages

**Owner:** Platform Engineering  
**Purpose:** Reusable libraries consumed by `services/` and `products/`.

| Package | Role |
| --- | --- |
| `common/` | Shared primitives |
| `core/` | Taifa core client SDKs (internal) |
| `authentication/` | Auth middleware/helpers |
| `networking/` | HTTP/gRPC clients |
| `storage/` | Blob/DB abstractions |
| `logging/` | Structured logging |
| `configuration/` | Env/config loading |

Version with semver; breaking changes require ARB.
