# Documentation standards

---

## Required metadata

Every doc:

```markdown
**Status:** Draft | Approved | Deprecated
**Owner:** squad or role
**Last reviewed:** YYYY-MM-DD
```

---

## Locations

| Type | Path |
| --- | --- |
| Enterprise architecture | `docs/architecture/` or repo `../docs/architecture/` |
| Platform packs | `platforms/{name}/` + `../docs/` hubs |
| Product TPOS | `products/{slug}/00-25` |
| ADRs | `docs/decisions/` |
| Runbooks | `docs/runbooks/` |

---

## Style

- Executive summary first  
- Mermaid for flows  
- Link don't duplicate platform packs

---

## Reviews

Documentation Review Board before Beta (TPOS).
