# Release Board

**Mandate:** Authorize production releases, coordinate trains, approve hotfixes and rollbacks.

---

## Scope

- Platform bi-weekly / monthly trains
- Product GA releases
- Emergency hotfix with rollback plan

---

## Checklist (minimum)

- [ ] CHANGELOG / release notes
- [ ] E2E green on staging
- [ ] Observability dashboards updated
- [ ] Runbook delta reviewed
- [ ] Security sign-off (if applicable)
