# 18. Merchant Pilot Governance Framework

**Owner:** Pilot Director / Head of Operations · **Accountable:** COO  

---

## Purpose

Govern live merchant pilots on Taifa Commerce without software redesign.

---

## Readiness gates (before Phase: Live sales)

| Track | Ready when |
| --- | --- |
| Pilot merchants | ≥ N onboarded (recommended 3–10) with mandatory checklist |
| Warehouses | Default WH live · receiving trained |
| Staff | Cashiers + warehouse certified for role apps |
| Customers | Acquisition plan (organic) logged |
| Deliveries | Mobility policy documented if offering delivery |
| Suppliers | ≥1 per merchant or exception |
| Wingas | Optional; if used, publish tested |
| Reporting | Weekly dashboard owner named |
| Governance | Steering cadence booked |

---

## Exit criteria (pilot success)

- Merchants run daily ops via SOPs  
- Inventory accuracy on target  
- Orders fulfill within SLA  
- Payments/settlements reconcile (0 unresolved Critical money issues)  
- CSAT / merchant satisfaction measured (non-zero n)  
- Support load manageable  
- ≥1 merchant reaches **Operationally Certified**  

---

## Scope freeze

**In:** Playbooks, training, support, recon, low-risk UX copy.  
**Out:** API redesign, inventory engine redesign, payment redesign, new modules.

---

## Decision rights

| Decision | Authority |
| --- | --- |
| Merchant go-live | Merchant Success + Store Ops + Settlement |
| PAY/SETTLE freeze | Ops + Finance |
| Operational certification | Certification board |
| Expand to next city / segment | COO + CCO after exit criteria |

---

## Evidence standard

KPI dictionary sources · recon logs · interview n (0 allowed) · ledger-linked claims only.
