# 17. Merchant Certification Checklist

**Owner:** Merchant Success + OpEx · **Accountable:** COO  
**Label:** Operationally Certified  

A merchant is **Operationally Certified** only when **all** boxes are evidenced.

---

## Requirements

### Inventory
- [ ] Accuracy meets target (≥ policy, default ≥ 95% sample)  
- [ ] Movements used for all adjusts  
- [ ] Health score ≥ 85 for 2 consecutive weeks  

### Payments & settlement
- [ ] Captures reconcile to `payment_ref`  
- [ ] Settlements complete successfully per schedule  
- [ ] **Zero** unresolved financial discrepancies  

### Orders
- [ ] Fulfillment within SLA (≥ target hit rate, default ≥ 90%)  
- [ ] Returns/refunds follow policy  

### Support
- [ ] Support standards met (SLA hit ≥ target)  
- [ ] No open Sev-1 attributable to merchant process  

### SOPs
- [ ] Daily open/close executed  
- [ ] Staff trained & attested  
- [ ] Onboarding mandatory steps complete  

---

## Outcome

| Result | Status |
| --- | --- |
| All evidenced | **Operationally Certified** |
| Any open | **Not certified** |
