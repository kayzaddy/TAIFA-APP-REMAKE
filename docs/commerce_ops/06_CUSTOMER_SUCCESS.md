# 6. Customer Success Playbook

**Owner:** Head of Customer Success · Support partner  

---

## Case types & SLAs

| Case | First response | Resolve | Owner |
| --- | --- | --- | --- |
| Account | ≤ 4h | ≤ 1 business day | Support |
| Order status | ≤ 2h | Same day | Support + Store |
| Delivery | ≤ 2h | Per Mobility SLA | Support + Warehouse |
| Payment | ≤ 1h (Critical if funds) | Same day | Support + Settlement |
| Refund | ≤ 4h | Per policy | Settlement + CS |
| Return | ≤ 4h | ≤ 3 business days | Warehouse + CS |
| Complaint | ≤ 4h | ≤ 2 business days | CS |
| Dispute / fraud | ≤ 2h | Risk timeline | Risk |
| Feedback / review | ≤ 1 business day | Logged | CS |
| Retention outreach | Weekly list | Logged | CS |

Every ticket: category, severity, timestamps, optional CSAT.

## Knowledge base topics

How payment works · Receipt / ledger ref · Returns window · Delivery ETA · Contact merchant  

## Escalation

Support → CS → Store Ops / Warehouse → Settlement/Risk → COO (Sev-1 customer impact)
