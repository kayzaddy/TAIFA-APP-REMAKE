# Product & Service Ownership

Ownership must always be explicit. Vacancies are a governance defect.

## Roles (per domain)

| Role | Responsibility |
| --- | --- |
| Business Owner | Outcomes, funding, prioritization |
| Product Owner | Backlog, UX, acceptance |
| Technical Owner | Design, code health, ADRs |
| Security Owner | Threat model, reviews, vulns |
| Data Owner | Classification, quality, retention |
| Operations Owner | SLOs, on-call, incidents |
| Platform Owner | Shared services alignment |
