# Engineering Culture

## Principles

1. Build once, reuse everywhere  
2. Platform before product  
3. Automation first  
4. Documentation first  
5. Security by default  
6. Privacy by design  
7. Everything observable  
8. Configuration over customization  
9. Backward compatibility  
10. Continuous improvement  
11. Evidence-based decisions (ADRs, metrics)  
12. Operational excellence  
13. Customer-centric engineering  
14. Long-term maintainability  

## Behaviors

- Prefer extending shared services over forking  
- Leave codebases cleaner than you found them  
- Escalate architectural doubt to ARB early  
- Celebrate postmortems that prevent repeats  
- Optimize for the next decade, not the next demo
