# 2. NFC Integration Guide

## Today

- Simulated NFC handshake in Flutter (`/tap`)
- Terminal capability flags on `AcceptanceTerminal` (`nfc_ready`, `softpos_ready`)
- Session metadata `nfc_meta` for attestation payloads

## Future

- Hardware NFC HCE / reader modes
- Device attestation + certificate validation
- SoftPOS Android certification
- Relay / clone terminal defenses

Payment capture remains unchanged when hardware lands.
