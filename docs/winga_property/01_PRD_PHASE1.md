# Winga Property — Phase 1 PRD

## Mission

Build the trusted property discovery foundation inside the Taifa Digital Ecosystem — not another listing website.

## Phase 1 scope

- Property domain model (categories, types, ownership)
- Listing CRUD with geo fields
- Photos and video media (URL-based foundation)
- Search and map pins
- Favorites and saved searches
- Verification workflow (draft → pending → verified)
- Django admin portal
- Flutter browse / detail / map toggle

## Out of scope (Phase 2+)

- AI natural language search
- Viewing Pass / paid unlock
- Live property mode
- Digital transactions
- VR / 360 tours

## Acceptance criteria

| Criterion | Status |
| --- | --- |
| Property listings operational | ✓ |
| Owners can manage properties | ✓ |
| Search works | ✓ |
| Maps work (pin foundation) | ✓ |
| Photos work | ✓ |
| Videos work | ✓ |
