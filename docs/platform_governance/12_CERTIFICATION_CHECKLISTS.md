# 12. Certification Checklist Library

**Owner:** Certification Board  
Use per platform; attach evidence links.

---

## A. Architecture Certification
- [ ] ARB approved  
- [ ] Threat model approved  
- [ ] ERD / boundaries approved  
- [ ] API standards verified  
- [ ] Reuse map (no duplicate ledger/identity)  
- [ ] Ownership & deprecation stated  

## B. Engineering Certification
- [ ] CI green on main  
- [ ] Unit + integration tests  
- [ ] Security tests (as applicable)  
- [ ] Performance budget or waiver  
- [ ] OpenAPI validation  
- [ ] Dependency + secrets scans clean  

## C. Security Certification
- [ ] AuthN/AuthZ review  
- [ ] Encryption & secrets  
- [ ] Vuln SLA compliance  
- [ ] Audit logging  
- [ ] IR playbooks  
- [ ] Pen-test (money/PII) if required  

## D. Operations Certification
- [ ] Ops handbook / SOPs  
- [ ] Runbooks  
- [ ] Monitoring + alerting  
- [ ] Incident procedures  
- [ ] On-call coverage  

## E. Business Certification
- [ ] Pilot real users/transactions  
- [ ] Domain KPIs met or waived with exec note  
- [ ] CSAT / retention evidence (n reported)  
- [ ] No unresolved Critical financial defects  

## F. Production Certification
- [ ] Production readiness checklist complete  
- [ ] Rollback + DR validated  
- [ ] Support ready  

## G. National Certification
- [ ] F + capacity + compliance  
- [ ] Multi-site ops model  
- [ ] Executive Steering approval  

**Rule:** Incomplete checklists = not certified. Feature count ≠ Business/National cert.
