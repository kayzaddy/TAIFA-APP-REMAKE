# 17. Continuous Improvement Playbook

**Owner:** OpEx · all domain owners  

---

## Loop (Stage 9 — never stops)

```
Observe → Measure → Analyze → Prioritize → Improve → Validate → Deploy → Review → Document
```

## Sources

Incidents · support themes · pilot interviews · scorecard gaps · audits · debt register  

## Rules

- Prefer playbook/training/UX-low-risk fixes before architecture change  
- Architecture changes go through ARB  
- Validate with metrics before closing action  
- Document in ops handbook / ADR as appropriate  

## Cadence

Weekly triage · Monthly CIP review in Platform Review · Quarterly theme deep-dives.
