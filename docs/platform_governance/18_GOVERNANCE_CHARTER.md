# 18. Platform Governance Charter

**Owner:** Executive Steering Committee  
**Effective:** v1.0  

---

## Purpose

Establish one lifecycle and certification system for the Taifa Digital Ecosystem.

## Boards & councils

| Body | Mandate |
| --- | --- |
| Architecture Board | G1, patterns, debt, deprecation |
| Engineering Board | G2, quality gates |
| Security Board | Security cert, exceptions |
| Product Council | Vision, experience G0/G3, prioritization |
| Operations Council | G4, ops excellence |
| Finance | Settlement integrity, money waivers |
| Risk | Risk acceptance, pilot risk |
| Compliance | Regulatory attestations |
| Certification Board | G7 |
| Executive Steering Committee | G8 national / strategic |

## Authority

Charter overrides ad-hoc “ship anyway” culture.  
No production without gates.  
No AI payment authorization — ever.

## Amendment

Requires Executive Steering + CTO + COO + CISO for constitutional changes ([`20_PLATFORM_CONSTITUTION.md`](20_PLATFORM_CONSTITUTION.md)).
