# 10. Pilot Execution Handbook

**Owner:** COO · Pilot Director  
**Extends:** Domain pilots (e.g. [`../winga_pilot/field/`](../winga_pilot/field/00_INDEX.md), [`../commerce_ops/18_PILOT_GOVERNANCE.md`](../commerce_ops/18_PILOT_GOVERNANCE.md))

---

## Standard pilot flow

1. Pilot planning (scope, cohort, KPIs, freezes)  
2. Participant recruitment  
3. Success metrics locked  
4. Weekly reviews  
5. Operational monitoring  
6. User interviews (**never invent**; n=0 allowed)  
7. Risk reviews  
8. Lessons learned  
9. Pilot closure → G6 evidence pack  

## Rules

- Real users · real transactions when money-involved  
- Organic acquisition preferred for validation  
- Scope freeze: no architecture redesign mid-pilot  
- Exit criteria domain-specific but always evidence-based  

## Gate G5 / G6

G5 = ready to start · G6 = validated with measured outcomes.
