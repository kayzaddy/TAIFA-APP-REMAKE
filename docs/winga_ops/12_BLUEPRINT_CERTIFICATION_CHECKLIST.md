# 12. Industry Blueprint Certification Checklist

**Owner:** Pilot Director + COO  
**Rule:** An industry is **Certified** only when **all** boxes are evidenced. Software readiness alone is insufficient.

---

## Certification requirements

### A. Operational playbooks proven
- [ ] Onboarding playbook used on ≥N real providers (Hotels: ≥8 live)  
- [ ] Winga certification path produced ≥N certified Wingas (Hotels: ≥8 earning)  
- [ ] Daily ops checklist run ≥20 consecutive business days  
- [ ] Settlement recon signed daily during live period  

### B. Customer value demonstrated
- [ ] ≥30 completed bookings (Hotels bar) **or** industry-specific bar  
- [ ] CSAT ≥ 4.2 (n sufficient)  
- [ ] Repeat booking interest evidenced (rate or interviews)  

### C. Provider value demonstrated
- [ ] ≥8 providers request continued participation (Hotels)  
- [ ] MBRs completed for live providers  
- [ ] Lead quality accepted as net-positive in reviews  

### D. Winga profitability demonstrated
- [ ] ≥8 Wingas with settled commissions  
- [ ] Median/typical income path documented (no fabrication)  

### E. Settlement proven
- [ ] Zero unresolved financial integrity issues  
- [ ] Zero commission calculation errors in field volume  
- [ ] Zero settlement discrepancies unresolved  

### F. Support sustainable
- [ ] SLA hit rate meets target  
- [ ] Ticket volume / booking within capacity model  
- [ ] Macros documented  

### G. Repeat demand verified
- [ ] Repeat bookings or verified intent data  

### H. Metrics meet targets
- [ ] KPI dictionary targets for industry met or waived with COO written exception
