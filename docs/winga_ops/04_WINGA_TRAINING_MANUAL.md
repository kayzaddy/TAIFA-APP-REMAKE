# 4. Winga Training Manual

**Owner:** Head of Winga Success  
**Rule:** Only **certified** Wingas may originate paid deals.

---

## Certification path

```
Registration → Identity (KYC) → Background check (as required)
→ Platform training → Sales → Negotiation → Ethics → Customer care
→ Commission rules → AI usage → Payment awareness → Policies
→ Knowledge assessment → Certification → Active roster
```

---

## Module outline

| Module | Outcomes | Pass criteria |
| --- | --- | --- |
| M0 Registration | Profile created | Complete profile |
| M1 Identity | KYC verified | Risk/KYC approved |
| M2 Background | Clear for brokerage | Policy pass |
| M3 Platform | Hub, desk, opportunities, wallet | Demo tasks |
| M4 Sales | Lead capture, hotel knowledge | Role-play |
| M5 Negotiation | Quote/counter/expiry | Role-play |
| M6 Ethics | No misrepresentation, no off-platform money | Attestation |
| M7 Customer care | Tone, escalation | Scenario quiz |
| M8 Commission | Pending / earned / settled; transparency UI | Quiz ≥80% |
| M9 AI assistant | Coaching only; **never** authorizes payment | Quiz 100% on money guard |
| M10 Payment awareness | Customer pays via Taifa; Idempotency | Quiz ≥80% |
| M11 Ops policies | SLAs, incidents, freezes | Attestation |
| M12 Assessment | Capstone | ≥80% + live observation |
| M13 Certification | Badge / status | Winga Success sign-off |

---

## Knowledge assessment (minimum)

1. Who can authorize payment? (Answer: customer via platform pay — not AI, not Winga forging)  
2. When does commission settle?  
3. What is the hotel response SLA?  
4. What do you do if customer asks to pay cash off-platform?  
5. How do you explain trust badges?

---

## Ongoing obligations

- Maintain activity (coaching if inactive >14 days)  
- Reputation monitoring  
- Refresher when policies change  
- Immediate suspension path for ethics/fraud (Risk)

---

## Training records

Store: date, trainer, scores, certificate ID, principal ID.  
Inactive / failed: cannot take new paid leads until recertified.
