# 3. Design System

Reuse existing Taifa Consumer Design System:

- Tokens: `taifa_colors.dart`, `taifa_dimens.dart`, `taifa_typography.dart`, `taifa_theme.dart`
- Shared widgets: `WalletCard`, `ServiceTile`, `QuickActionButton`, `TaifaBottomNav`, `PromoCard`, `TaifaLogo`
- Super App additions: `SuperSearchBar`, `HomeJourneyRail`, Pay hub list tiles

Material 3 · dark mode · accessibility via theme contrast · localization-ready strings (EN/SW mixed where product already does).

Do not invent a parallel design language.
