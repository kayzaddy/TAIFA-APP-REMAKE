# 1. Consumer Experience Guide

## Vision

Users accomplish goals without thinking about platforms. The Super App orchestrates:

| Need | Experience | Backend |
| --- | --- | --- |
| Pay | `/pay` · `/scan` · Wallet · MAP | Payments + MAP |
| Ride | Mobility tab / Home | Trips API |
| Shop | Food · Commerce · Winga | Commerce / Winga / MOS |
| Book | Hotels · Flights · Tourism | Commerce APIs |
| Ask | AI tab | AI gateway (assist only) |
| Find | Universal Search | Local catalog → routes |

## Home

- Wallet card (existing wallet summary / remote when enabled)
- Universal search bar → `/search`
- Quick actions: Send · Scan · Top up · Pay hub
- Journey rail (personalized shortcuts)
- Services grid (ecosystem modules)
- Promo card

## Principles

Modular · reusable · personalized · secure · observable · offline-aware · API-driven  
**Never** duplicate payments, identity, commerce, mobility, or Winga logic.
