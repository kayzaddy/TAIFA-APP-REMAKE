# 18 — Success Metrics

---

## Executive summary

Framework for **product success metrics**—every product defines in `22_SUCCESS_METRICS.md` using this taxonomy.

---

## Metric categories

| Category | Examples |
| --- | --- |
| **Adoption** | MAU, activation rate, onboarding completion |
| **Engagement** | DAU/MAU, session length, feature adoption |
| **Outcome** | Revenue, TPV, tasks completed, time saved |
| **Quality** | NPS, CSAT, error rate, crash-free |
| **Trust** | Fraud rate, support tickets, security incidents |
| **Efficiency** | Cost per transaction, support cost per user |

---

## Leading vs lagging

- **Leading:** funnel steps, API success, pilot feedback  
- **Lagging:** revenue, retention, national adoption %

---

## Platform metrics (do not duplicate in product silos)

- TNPI TPV — TNPI ops  
- TIP availability — integration ops  
- Use **product-specific** slices via Analytics (`15_ANALYTICS_PLAN.md`)
