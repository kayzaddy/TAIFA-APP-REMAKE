# 17 — Definition of Done

---

## Executive summary

DoD for orchestration stories and releases.

---

## Story DoD

OpenAPI/events updated · state machine tests · idempotency test · integration test · audit verified · correlation_id in logs · no secrets in logs · load test for critical paths.

---

## Release DoD

Runbook · dashboards · rollback · on-call rotation briefed · feature flag doc.
