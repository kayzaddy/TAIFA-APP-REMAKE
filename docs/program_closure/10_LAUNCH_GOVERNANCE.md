# 10. Launch Governance Manual

**Owner:** Executive Steering · Launch Review Board  

---

## Bodies (execution)

| Body | Cadence | Mandate |
| --- | --- | --- |
| Executive Steering Committee | Monthly + ad hoc G8 | Strategy, national GO |
| Architecture Board | Per change + quarterly | Baseline integrity |
| Operations Council | Weekly | Ops excellence, freezes |
| Security Review Board | Biweekly / ad hoc | Sec cert, exceptions |
| Launch Review Board | Per launch | G8 pack review |
| Pilot Review Board | Weekly in pilot | G5/G6 |
| Certification Committee | Ad hoc G7 | Evidence certification |

## Operating cadence

| Ritual | When |
| --- | --- |
| Weekly ops + eng + pilot | Weekly |
| Monthly executive review | Monthly |
| Quarterly platform review | Quarterly |
| Annual platform audit | Annual |

## Launch path

Architecture → Engineering → Security → Operations → Pilot → Business → Certification → Production Readiness → **Executive Go/No-Go**

No production launch without executive approval.
